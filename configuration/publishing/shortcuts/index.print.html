Keyboard Shortcuts

Besides the keys every browser knows, the theme brings shortcuts of its own. Those of a button are also shown in its tooltip.

Shortcut Action
CTRL ALT n Shows or hides the menu in the mobile layout.
CTRL ALT f Puts the focus into the search box, pressed again back into the content.
CTRL ALT t Shows or hides the table of contents.
CTRL ALT w Opens the page for editing, if configured.
CTRL ALT p Opens the print view, if configured.
🡐 / 🡒 Goes to the previous or next page. If the focus is on a tab, selects the previous or next tab instead, as HOME and END select the first and last one.
ALT 🡑 / ALT 🡓 Scrolls to the previous or next heading of the page.
🡐 / 🡒 / 🡑 / 🡓 Pans a Mermaid graph, if the focus is on it and it is zoomable.
+ / - Zooms into or out of a Mermaid graph, if the focus is on it and it is zoomable.
ESC Closes what was opened, like the menu of the mobile layout, the table of contents or the lightbox of an image or graph, and clears the search.
