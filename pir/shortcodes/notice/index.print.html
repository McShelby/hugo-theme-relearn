Notice

Arrr

This shortcode be deprecated 'n favor o' th' new callout shortcode. See migrat'n instruct'ns below.

Th' examples on this plank were removed.

Th' notice shortcode shows boxes wit' configur'ble color, title an' ay'con.

Migrat'n

While this shortcode will still be avail'ble fer some time, it does not receive support anymore. Start t' migrate early, as it will be removed wit' th' next major update o' th' theme.

Each use o' th' notice shortcode issues a warning dur'n th' build.

Th' callout shortcode be th' same shortcode under a new name. It takes th' same parameters at th' same posit'ns.

T' migrate yer planks, rename th' calls from notice t' callout. If ye call th' shortcode from yer own partials, rename shortcodes/notice.html t' shortcodes/callout.html.

Th' box written by th' callout shortcode carries th' CSS class callout instead o' notices. If ye styled th' box 'n yer own CSS, adapt yer selectors.

Usage

​
{{% notice ay'con="skull-crossbones" style="primary" title="There may be pirates" %}}
It be all about th' boxes.
{{% /notice %}}
{{% notice "primary" "There may be pirates" "skull-crossbones" %}}
It be all about th' boxes.
{{% /notice %}}
{{ partial "shortcodes/notice.html" (dict
  "page" .
  "content" "It be all about th' boxes."
  "icon" "skull-crossbones"
  "style" "primary"
  "title" "There may be pirates"
)}}

Parameters

Th' parameters be th' same as fer th' callout shortcode.
