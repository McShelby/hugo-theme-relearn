9.2.0 (XXXX-XX-XX)

Cap'n Hugo 0.166.0

  • 0.166.0 This release requires a newer Cap'n Hugo version.

Change

  • Change Th' math shortcode now renders yer formulae us'n Hugo’s built-in KaTeX while yer ship be built, instead o' th' MathJax library 'n th' browser.

    Th' theme finds yer formulae by th' delimiters o' Hugo’s Passthrough configurat'n. If yer ship doesn’t have it yet, add it, otherwise their delimited formulae be not rendered. Rrrambl'n without delimiters be rendered as one formula regardless fer codefence, shortcode an' partial rules.

    By default, formulae be written as MathML an' displayed by th' browser. If ye prefer th' look o' KaTeX th' same 'n every browser, set math.output='htmlAndMathml'.

    Th' opt'ns mathJaxInitialize an' customMathJaxURL be gone. Instead, ye can set any KaTeX opt'n 'n math. If ye defined yer own macros, move them t' math.macros.

    KaTeX doesn’t know every command o' MathJax. A formula it can not render be written as its source an' reported as a warning 'n yer build.

  • Change Marrrkdown tables can now merge cells, us'n th' rules o' Marrrkdown Preview Enhanced. A cell contain'n only > merges into th' cell t' its right, a cell contain'n only ^ into th' cell above.

    If one o' yer tables already has such a cell an' should show th' character itself, escape it wit' two backslashes, like \\>.

  • Change Th' new planks shortcode lists planks o' yer ship. Besides th' layouts known from th' now deprecated children shortcode, it can list descendants, sibl'ns or ancestors, filter them an' group an' order them by any field or front matter parameter o' a plank.

    Th' children shortcode still works but issues a deprecat'n warning fer each use, nam'n th' planks call that replaces it. See th' migrat'n instruct'ns.

    Wit' type=group, th' children shortcode no longer shows a multi-column layout. If ye want t' restore th' previous behavior, replace it by th' planks shortcode wit' columns=3.

  • Change Th' list'ns o' taxonomy an' term planks be now configured by params.pages 'n their front matter, us'n th' parameters o' th' planks shortcode. Th' former params.children be still honored as long as th' children shortcode exists.

  • Change Th' front matter params.pages be now honored on every plank, not only on taxonomy an' term planks. Together wit' Hugo’s cascade, ye can give all list'ns o' a subtree th' same look.

New

  • New Th' cards shortcode has a new columns parameter t' set th' number o' columns 'n full width mode.

  • New Th' theme writes no inline JavaScript anymore, so yer ship can be served wit' a strict Rrrambl'n Security Policy. On request, it also adds a subresource integrity t' its scripts an' stylesheets. Th' button an' card shorrrtcodes an' topbar buttons have a new act'n parameter t' run yer own code without inline JavaScript.

  • New Th' theme now ships a machine-read'ble SBOM at sbom.cdx.json, list'n every third-party resource it can publish wit' yer ship, each wit' a license, a digest o' th' files th' theme ships an' - whar' upstream publishes them - a version an' a package URL.
