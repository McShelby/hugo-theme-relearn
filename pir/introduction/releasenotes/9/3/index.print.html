9.3.0 (XXXX-XX-XX)

Change

  • Change Level one head'ns, th' section titles o' th' sidebar menu an' th' title o' th' openapi shortcode be no longer forced t' uppercase but show as written. Th' uppercase look, inherited from th' Learrrn theme, became iconic fer this theme, but it be strongly opinionated an' looks strange wit' many fonts, especially script an' serif fonts.

    If ye want t' keep th' iconic look fer head'ns an' th' sidebar menu, add th' follow'n t' yer assets/css/custom.css:

    ​
    h1,
#R-sidebar .nav-title {
  text-transform: uppercase;
}

  • Change Th' borders o' tables an' th' border o' a zoom'ble Merrrmaid diagram, as well as th' backgrounds o' table headers an' every second table row, now take their color from th' theme variant vari'ble BOX-NEUTRAL-color, which inherits from BOX-GREY-color. Formerly they were a fixed gray that could not be changed by a variant an' was too faint 'n th' high contrast variants. Th' same goes fer th' border o' tabs wit' style=transparent.

    Th' border o' code blocks, CODE-BLOCK-BORDER-color, now inherits from BOX-NEUTRAL-color instead o' CODE-BLOCK-BG-color. Th' shipped variants were adjusted t' this.

    If yer own variant does not set CODE-BLOCK-BORDER-color, its code blocks now get a vis'ble border 'n th' neutral color. As code boxes take their color from it, th' title an' frame o' callouts an' tabs wit' style=code change as well. T' restore th' previous look, set CODE-BLOCK-BORDER-color 'n yer variant t' th' value o' CODE-BLOCK-BG-color, or set BOX-CODE-color t' only change code boxes.

    If yer variant sets BOX-NEUTRAL-color or BOX-GREY-color t' a strong color, yer tables, Merrrmaid diagrams an' transparent tabs now show it as well.

  • Change Th' logo o' a variant be now set 'n th' new params o' th' variant, which holds th' values that override th' site’s params while th' variant be active. Sett'n logo directly on th' variant be deprecated an' you’ll get a warning; it still works fer now.

    Change { identifier = 'neon', logo = { src = '/images/logo-neon.svg' } } t' { identifier = 'neon', params = { logo = { src = '/images/logo-neon.svg' } } }.

  • Change Print'n a plank an' its print version now use a print variant wit' colors made fer paper on top, by default relearn-light. Formerly th' print used a fixed look that no variant could change.

    Ye can choose th' print variant o' yer ship wit' th' new themeVariantPrint option, or one fer each variant wit' its new print parameter. A variant nam'n itself prints wit' its own fonts.

    Th' variables PRINT-MERMAID-theme, PRINT-OPENAPI-theme an' PRINT-OPENAPI-CODE-theme were removed. If you’ve set them, set MERMAID-theme, OPENAPI-theme an' OPENAPI-CODE-theme 'n yer copy o' th' print variables instead, or marked !important 'n yer print variant.

  • Change Th' color variant relearn-bright be deprecated an' will be removed wit' th' next major release. You’ll get a warning if ye use it.

    T' keep it, copy assets/css/theme-relearn-bright.css from th' theme into yer site’s assets/css directory under a different name, like theme-my-bright.css, an' use that name 'n th' themeVariant option.

  • Change Th' color variant relearn has only been kept fer compatibility since 3.0.0, whar' relearn-light replaced it. It will be removed wit' th' next major release an' you’ll now get a warning if ye use it.

    It be identical t' relearn-light, use that name 'n th' themeVariant option instead.

New

  • New Th' new color variants tome-light an' tome-dark give yer ship th' look o' a book, wit' calligraphic titles. They be th' first shipped variants wit' tinted instead o' grey rrrambl'n backgrounds, an' show how colors th' theme derives, like shadows, follow such a tint. Use them as a start'n point fer yer own tinted variant.

    Many o' th' changes 'n this release be due t' support this variant.

  • New Th' new color yellow can be used as style 'n every shortcode tak'n one an' set wit' BOX-YELLOW-color 'n yer theme variant. Each shipped variant picks a yellow that be read'ble wit' its title an' text colors.

    T' keep it apart from yellow, orange - an' wit' it th' note severity - be now a true orange instead o' an amber, an' darker so its titles be read'ble as well.

  • New Th' entries o' th' variant switcher can now be grouped by putt'n dividers into th' themeVariant option. A divider wit' a name labels its group.
